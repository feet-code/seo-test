The most useful tutoring parent progress reporting workflow template is a small operating record. It should answer what is happening, who owns it, what evidence exists, and when the next decision occurs. This structure works in a spreadsheet, database, or focused application.

## Recommended record fields

| Field | Why it exists | Update point |
|---|---|---|
| Student and program | Prevents the record from depending on memory or an inbox search | Define the reporting period and required evidence |
| Reporting period | Prevents the record from depending on memory or an inbox search | Collect structured tutor session notes |

## Suggested statuses

Use workflow statuses that describe reality: **Define The Reporting Period And Required Evidence → Collect Structured Tutor Session Notes → Flag Missing Or Unclear Observations → Review And Publish The Parent Update → Record Questions And Next Period Focus**. Add **Waiting** only when you also capture a waiting reason and review date. Add **Closed—Not Completed** when an item legitimately ends without the desired outcome.

## Follow-up rules

- When a required session note is missing near publication, assign a next action and review date.
- When multiple tutors record conflicting progress, assign a next action and review date.
- When a parent asks a question that needs tutor or director review, assign a next action and review date.

Avoid reminders with no stop condition. A rule should say when it starts, who receives it, what counts as a response, and when a person should take over.

## Example records

- A reading student has attendance logged but no skill evidence
- Two tutors use different names for the same algebra goal
- A parent asks why the next focus changed from the previous report

For each example, write the current status, next action, owner, and supporting evidence. This makes the template testable with real work rather than idealized sample data.

## Quality-control rules

- Every open parent progress update needs one owner and a next review time
- Completion requires recorded evidence that each reporting period produces an approved, evidence-based parent update with clear progress and next focus
- Automated reminders stop after verified completion or a documented closed reason
- Keep tutoring schedule and student record system as the system of record; only necessary coordination data belongs here

Before adding automation, run the template manually for a week. Remove ambiguous fields and confirm that two different users classify the same situation the same way. Consistency matters more than having a long form.
