A checklist for theater prop and costume return tracking should prevent missing decisions, not merely prove that somebody clicked boxes. The checklist below is designed for community theaters and volunteer-led stage-production teams and centers on one result: **every production asset has assigned custody, condition evidence, return deadline, storage destination, and an explicit lost damage repair or closed outcome**.

## Before the work starts

- Confirm Production asset and inventory ID
- Confirm Description components size and condition
- Confirm Owner lender and storage origin
- Confirm Issued to purpose date and deadline

Also name the owner and the expected completion condition. If either is unknown, the work is not ready to enter the active queue.

## While the work is moving

- Update Issue assets to a person production and purpose
- Update Record condition components and return rule
- Update Transfer custody during rehearsal performance or strike
- Update Inspect and route cleaning repair or storage
- Update Close only after every component is reconciled

Every update should change a decision. Notes such as “followed up” are weak unless they also include the channel, result, next date, and owner.

## Before marking it complete

- Verify Custody transfers and acknowledgments
- Verify Return condition photos and missing pieces
- Verify Cleaning repair replacement and owner
- Verify Final storage lender return or closed reason

Confirm that the actual outcome—not just an activity—has been recorded. If the process ended early, use a closed reason rather than deleting the record.

## Copy-and-paste weekly review

- [ ] Review records where an asset leaves controlled storage
- [ ] Review records where custody changes or return deadline passes
- [ ] Review records where inspection finds missing damaged or cleaning-required components

- [ ] Check for signing out a costume package as one unnamed item
- [ ] Check for moving props between departments without transfer
- [ ] Check for marking returned while cleaning is pending
- [ ] Check for closing a borrowed asset before lender acknowledgment

## Make the checklist measurable

Choose one metric before the next cycle. Good options for this workflow are On-time return rate, Missing-component rate, Ready-for-next-use time. A checklist that never changes a metric or prevents a known failure mode is probably administrative overhead.

## Assign ownership and escalation

Put one role—not a group—next to every item that can remain open. Define a backup owner and an escalation time for work that affects a customer, client, participant, or delivery promise. During review, separate **not started**, **waiting on someone**, and **failed validation**; those states need different actions. If a checklist item repeatedly waits on the same dependency, redesign the intake or handoff instead of adding more reminder boxes.
