The most useful sign installation readiness tracking template is a small operating record. It should answer what is happening, who owns it, what evidence exists, and when the next decision occurs. This structure works in a spreadsheet, database, or focused application.

## Recommended record fields

| Field | Why it exists | Update point |
|---|---|---|
| Customer, job, and site | Prevents the record from depending on memory or an inbox search | Open install readiness from the approved job |
| Approved proof and fabricated items | Prevents the record from depending on memory or an inbox search | Verify fabrication, packaging, and hardware |
| Survey dimensions and mounting condition | Prevents the record from depending on memory or an inbox search | Confirm site survey, permit, access, and customer window |

## Suggested statuses

Use workflow statuses that describe reality: **Open Install Readiness From The Approved Job → Verify Fabrication Packaging And Hardware → Confirm Site Survey Permit Access And Customer Window → Match Qualified Crew And Equipment → Run Final Dispatch Review And Release The Install Packet**. Add **Waiting** only when you also capture a waiting reason and review date. Add **Closed—Not Completed** when an item legitimately ends without the desired outcome.

## Follow-up rules

- When an installation approaches dispatch cutoff, assign a next action and review date.
- When fabrication, permit, site, crew, equipment, or weather changes, assign a next action and review date.
- When final review finds a mismatch with the approved job, assign a next action and review date.

Avoid reminders with no stop condition. A rule should say when it starts, who receives it, what counts as a response, and when a person should take over.

## Example records

- A lift permit is missing for a channel-letter install
- The landlord changes the allowed work window
- Fabricated panels are ready but the correct anchors are not packed

For each example, write the current status, next action, owner, and supporting evidence. This makes the template testable with real work rather than idealized sample data.

## Quality-control rules

- Every open sign installation readiness item needs one owner and a next review time
- Completion requires recorded evidence that every installation dispatch has verified product, site, permission, equipment, crew, and customer readiness
- Automated reminders stop after verified completion or a documented closed reason
- Keep the estimate, job, proof, production, inventory, and installation system as the system of record; only necessary coordination data belongs here

Before adding automation, run the template manually for a week. Remove ambiguous fields and confirm that two different users classify the same situation the same way. Consistency matters more than having a long form.
