Fabrication completion does not guarantee install readiness when permits, site access, survey dimensions, hardware, equipment, crew, weather, and customer windows remain open. The recurring failures are usually process-design problems rather than motivation problems. For independent sign shops, commercial printers, and display fabricators, these are the mistakes worth finding before buying or building software.


### 1. Scheduling from an expected fabrication date

This usually survives because the workflow records activity but not the decision that activity was meant to produce. Add **Approved proof and fabricated items** at the point of work and enforce this guardrail: Completion requires recorded evidence that every installation dispatch has verified product, site, permission, equipment, crew, and customer readiness When the exception occurs, keep it visible instead of repairing it privately in email.

### 2. Sending crew without the approved site-contact window

This usually survives because the workflow records activity but not the decision that activity was meant to produce. Add **Survey dimensions and mounting condition** at the point of work and enforce this guardrail: Automated reminders stop after verified completion or a documented closed reason When the exception occurs, keep it visible instead of repairing it privately in email.

### 3. Loading the sign but not mounting hardware

This usually survives because the workflow records activity but not the decision that activity was meant to produce. Add **Permit or landlord approval** at the point of work and enforce this guardrail: Keep the estimate, job, proof, production, inventory, and installation system as the system of record; only necessary coordination data belongs here When the exception occurs, keep it visible instead of repairing it privately in email.

### 4. Assuming a prior survey still reflects site conditions

This usually survives because the workflow records activity but not the decision that activity was meant to produce. Add **Access contact and install window** at the point of work and enforce this guardrail: Every open sign installation readiness item needs one owner and a next review time When the exception occurs, keep it visible instead of repairing it privately in email.

## Audit five recent records

Pick five completed or abandoned examples and ask:

- Can we reconstruct customer, job, and site without asking the original owner?
- Can we reconstruct approved proof and fabricated items without asking the original owner?
- Can we reconstruct survey dimensions and mounting condition without asking the original owner?
- Can we reconstruct permit or landlord approval without asking the original owner?
- Can we reconstruct access contact and install window without asking the original owner?

If the answer is no, improve the capture point rather than adding a later reporting step. Reports cannot recover decisions that were never recorded.

## Use mistakes as software requirements

Turn every frequent failure into a testable requirement. “Better visibility” is vague; “show every record with no owner or next date” can be tested. “More automation” is vague; “stop reminders after the completion condition is recorded” can be tested.
