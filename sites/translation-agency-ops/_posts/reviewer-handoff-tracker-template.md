The most useful translation reviewer handoff tracking template is a small operating record. It should answer what is happening, who owns it, what evidence exists, and when the next decision occurs. This structure works in a spreadsheet, database, or focused application.

## Recommended record fields

| Field | Why it exists | Update point |
|---|---|---|
| Client, project, and job | Prevents the record from depending on memory or an inbox search | Prepare the controlled review package |
| Language and file set | Prevents the record from depending on memory or an inbox search | Assign the reviewer and scope |

## Suggested statuses

Use workflow statuses that describe reality: **Prepare The Controlled Review Package → Assign The Reviewer And Scope → Obtain Handoff Acceptance → Track Comments And Returned Version → Reconcile Changes And Release The Next Stage**. Add **Waiting** only when you also capture a waiting reason and review date. Add **Closed—Not Completed** when an item legitimately ends without the desired outcome.

## Follow-up rules

- When a reviewer has not accepted near the start threshold, assign a next action and review date.
- When source or target files change after handoff, assign a next action and review date.
- When returned comments conflict or exceed agreed scope, assign a next action and review date.

Avoid reminders with no stop condition. A rule should say when it starts, who receives it, what counts as a response, and when a person should take over.

## Example records

- A medical reviewer receives files but not the client glossary
- The source document changes during linguistic review
- Two reviewers edit separate copies of the same target file

For each example, write the current status, next action, owner, and supporting evidence. This makes the template testable with real work rather than idealized sample data.

## Quality-control rules

- Every open translation review handoff needs one owner and a next review time
- Completion requires recorded evidence that every review handoff transfers the correct version, scope, references, deadline, and explicit acceptance to the next reviewer
- Automated reminders stop after verified completion or a documented closed reason
- Keep TMS, translation memory, glossary, and approved source files as the system of record; only necessary coordination data belongs here

Before adding automation, run the template manually for a week. Remove ambiguous fields and confirm that two different users classify the same situation the same way. Consistency matters more than having a long form.
