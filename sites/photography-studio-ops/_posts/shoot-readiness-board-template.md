The most useful photography shoot readiness tracking template is a small operating record. It should answer what is happening, who owns it, what evidence exists, and when the next decision occurs. This structure works in a spreadsheet, database, or focused application.

## Recommended record fields

| Field | Why it exists | Update point |
|---|---|---|
| Client, shoot, and contract | Prevents the record from depending on memory or an inbox search | Create the readiness packet from the booking |
| Date, call time, and duration | Prevents the record from depending on memory or an inbox search | Confirm scope, subjects, location, and schedule |
| Location and access contact | Prevents the record from depending on memory or an inbox search | Assign crew, equipment, props, and access needs |
| Subject or shot list | Prevents the record from depending on memory or an inbox search | Resolve weather, permission, or client exceptions |
| Crew and responsibilities | Prevents the record from depending on memory or an inbox search | Run the final go review and distribute the call sheet |
| Equipment, props, and backup | Prevents the record from depending on memory or an inbox search | Create the readiness packet from the booking |
| Permission, weather, and contingency status | Prevents the record from depending on memory or an inbox search | Confirm scope, subjects, location, and schedule |
| Client confirmation and go decision | Prevents the record from depending on memory or an inbox search | Assign crew, equipment, props, and access needs |

## Suggested statuses

Use workflow statuses that describe reality: **Create The Readiness Packet From The Booking → Confirm Scope Subjects Location And Schedule → Assign Crew Equipment Props And Access Needs → Resolve Weather Permission Or Client Exceptions → Run The Final Go Review And Distribute The Call Sheet**. Add **Waiting** only when you also capture a waiting reason and review date. Add **Closed—Not Completed** when an item legitimately ends without the desired outcome.

## Follow-up rules

- When a shoot approaches its final review, assign a next action and review date.
- When location, subject, weather, scope, or crew changes, assign a next action and review date.
- When required access, permission, equipment, or client approval remains open, assign a next action and review date.

Avoid reminders with no stop condition. A rule should say when it starts, who receives it, what counts as a response, and when a person should take over.

## Example records

- A retail shoot lacks loading-dock access
- Rain moves an outdoor portrait session to its backup
- A client adds products after lenses and surfaces are packed

For each example, write the current status, next action, owner, and supporting evidence. This makes the template testable with real work rather than idealized sample data.

## Quality-control rules

- Every open shoot readiness item needs one owner and a next review time
- Completion requires recorded evidence that every scheduled shoot reaches a verified go, revised, or postponed decision with people, place, scope, and production resources aligned
- Automated reminders stop after verified completion or a documented closed reason
- Keep the studio CRM, contract, gallery, asset, and delivery platform as the system of record; only necessary coordination data belongs here

Before adding automation, run the template manually for a week. Remove ambiguous fields and confirm that two different users classify the same situation the same way. Consistency matters more than having a long form.
